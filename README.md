# The Ram Sham Production

Luxury Indian wedding photography & cinematography studio based in Delhi, capturing timeless stories worldwide.

## Tech Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- GSAP animations

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
